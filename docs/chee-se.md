## 1. 작업 목적

MediaPipe Face Detection을 활용하여 \*\*제한 시간 안에 얼굴을 지정된 FACE ZONE으로 이동시키고, 선택한 캐릭터와 함께 순간 사진을 촬영하는 게임 `CHEE-SE!`\*\*를 구현한다.

# 8. MediaPipe 얼굴 감지

게임 진행 중 MediaPipe Face Detection을 사용한다.

판정 기준은 얼굴 랜드마크 일부가 아니라 **Face Detection의 얼굴 Bounding Box**를 기준으로 한다.

FACE ZONE:

```text
zoneLeft
zoneTop
zoneRight
zoneBottom
```

얼굴 Bounding Box:

```text
faceLeft
faceTop
faceRight
faceBottom
```

성공 조건:

```text
faceLeft >= zoneLeft
faceTop >= zoneTop
faceRight <= zoneRight
faceBottom <= zoneBottom
```

즉 얼굴 Bounding Box 전체가 FACE ZONE 안에 들어온 경우만 성공으로 판단한다.

---

# 9. FACE ZONE 생성

매 라운드마다 새로운 FACE ZONE을 생성한다.

## 비율

다음 중 하나를 무작위 선택한다.

```text
3:4
4:5
```

가로형 / 세로형 모두 허용한다.

예:

```text
3:4
4:3
4:5
5:4
```

중 하나가 될 수 있다.

## 위치

FACE ZONE은 웹캠 화면 전체 범위 내에서 랜덤하게 이동한다.

화면의 다음 영역 모두 사용할 수 있어야 한다.

- 상단
- 하단
- 좌측
- 우측
- 중앙
- 네 모서리
- 화면 가장자리

단, FACE ZONE 자체가 웹캠 화면 밖으로 벗어나서는 안 된다.

# 14. 캐릭터 위치

캐릭터는 FACE ZONE 중앙에 배치하지 않는다.

다음 위치 중 하나를 선택한다.

```text
상단
하단
좌측
우측
```

그리고 선택된 테두리에 밀착하여 배치한다.

예:

```text
┌──────────────┐
│  CHARACTER   │
│              │
│     FACE     │
│              │
└──────────────┘
```

또는

```text
┌──────────────┐
│              │
│     FACE     │ CHARACTER
│              │
└──────────────┘
```

실제 캐릭터는 반드시 FACE ZONE 내부에 있어야 한다.

# 17. 성공 판정

제한 시간 안에 얼굴 Bounding Box 전체가 FACE ZONE 내부로 들어오면 성공이다.

점수:

```text

```

성공 즉시:

1. 응답 시간 기록
2. 점수 +5
3. 누적 점수 갱신
4. 웹캠 화면 캡처
5. 캐릭터가 포함된 최종 게임 화면 캡처
6. 성공 효과음 재생
7. 해당 라운드 종료

성공 판정은 한 라운드당 한 번만 발생해야 한다.

# 28. 베스트 사진 선정

성공 사진 중 베스트 사진 후보를 선정한다.

다음 조건에 해당하는 사진은 후보에서 제외한다.

---

## 조건 1. 캐릭터 얼굴 가림

캐릭터와 얼굴 Bounding Box의 겹침 정도를 계산한다.

캐릭터가 얼굴 영역의:

```text
80% 이상
```

가린 경우 제외한다.

---

## 조건 2. 흔들림 / 초점 불량

이미지 선명도를 계산한다.

예:

```text
Laplacian variance
```

등의 방법을 사용할 수 있다.

프로젝트에 기존 이미지 품질 판단 로직이 존재하는 경우 기존 방식을 우선 사용한다.

---

## 조건 3. 눈 감김

베스트 사진 판정 단계에서 MediaPipe Face Mesh를 사용할 수 있다.

눈 랜드마크를 기반으로 EAR 또는 이에 준하는 기준을 사용하여 눈 감김을 판정한다.

눈이 감긴 사진은 베스트 사진 후보에서 제외한다.

Face Mesh는 베스트 사진 판정 용도로 사용하며 기본 게임 성공 판정은 Face Detection Bounding Box 기준을 유지한다.

# 29. 제외 사진

베스트 사진 선정 과정에서 제외된 사진도 삭제하지 않는다.

결과 화면에:

```text
제외된 사진 확인
```

토글을 제공한다.

토글 OFF:

```text
제외 사진 숨김
```

토글 ON:

```text
제외 사진 표시
```

각 사진에는 가능하면 제외 이유도 저장한다.

예:

```text
캐릭터 얼굴 가림
눈 감음
초점 불량
```

# 35. 타이머 주의사항

- 실패

- 게임 종료
- 컴포넌트 unmount

중복 타이머가 생성되지 않도록 한다.

---

# 36. MediaPipe 호출 주의사항

MediaPipe Face Detection이 동시에 여러 번 실행되지 않도록 한다.

이전 inference가 끝나지 않은 상태라면 새로운 inference 호출을 무조건 누적하지 않는다.

가능한 구조:

```text
웹캠 frame
↓
inference 가능 여부 확인
↓
Face Detection
↓
결과 처리
↓
다음 frame
```

---

# 37. 카메라 정리

게임 종료 또는 페이지 이동 시 MediaStream track을 종료한다.

예:

```ts
stream.getTracks().forEach(track => track.stop());
```

카메라가 백그라운드에서 계속 실행되지 않도록 한다.
